# Bike Sales Agentic — Prueba Técnica EAN

Proyecto en construcción. Ver docs/ (pendiente) para arquitectura completa.

## Cómo correr lo que hay hasta ahora

1. Instala dependencias: `pip install -r requirements.txt`
2. Prueba la tool 1 sola: `python tools/calculadora_metricas.py`
3. Prueba la tool 2 sola: `python tools/consulta_ventas.py`
4. Prueba el orquestador con Gemini real (requiere gcloud configurado):
   `python -m orchestrator.main`
